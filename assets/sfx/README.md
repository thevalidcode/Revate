# Sound Effects

This directory contains sound effect samples used by Revate for the auto-SFX feature.

## Current Status

The `.wav` files in this directory are placeholder files. You need to replace them with actual sound samples.

## Required Samples

- `click.wav` - A short click sound for mouse clicks
- `typing.wav` - A short typing/keystroke sound

## Licensing

All sound samples must be compatible with the MIT license used by Revate.
We recommend using CC0 (public domain) samples or creating your own.

## Sources for CC0 Samples

- [Freesound.org](https://freesound.org/) - Filter by CC0 license
- [OpenGameArt.org](https://opengameart.org/) - Various sound effects
- Create your own using a synthesizer or field recording

## Attribution

If you use samples that require attribution (not CC0), please add attribution
information to this README and ensure the license is compatible with MIT.
